# 2D Shooter Restart

The prior 3D space prototype was removed from the playable Godot project and its game-specific C++ source. A small Godot 4.6 2D graybox now demonstrates movement, aiming, hitscan damage, breakable props, temporary debris, and a jointed ragdoll.

Generic godot-cpp example classes and the PB2/Unity reference folders remain. They are not loaded by the new game.

Validation target: run `main/project/tests/runtime_smoke.gd` with Godot 4.6 headless. No runtime validation has been recorded yet.
